# Telegram бот для подготовки к ЕГЭ (Задание 5: Паронимы)

Этот бот помогает готовиться к ЕГЭ по русскому языку, задание 5 — паронимы и лексические нормы.

## Выбор библиотеки

Для создания бота была выбрана библиотека **pyTelegramBotAPI (telebot)** версии 4.14.0.

**Причины выбора:**
- Простота в использовании и установке
- Не требует компиляции нативных библиотек (в отличие от aiogram)
- Хорошая документация и активное сообщество
- Стабильная работа на Windows
- Поддержка инлайн-клавиатур и callback-запросов

## Установка и запуск

1. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Создайте файл `.env` в корне проекта:**
   ```bash
   cp .env.example .env
   ```

3. **Получите токен бота от @BotFather в Telegram и добавьте его в `.env`:**
   ```
   BOT_TOKEN=ваш_токен_здесь
   ```

4. **Запустите бота:**
   ```bash
   python main.py
   ```

## Функционал бота

- **Команда /start**: Главное меню с выбором режима
- **📚 Режим тренировки**: Случайные вопросы с выбором правильного паронима
- **📖 Режим словаря**: Просмотр всех паронимов с определениями и примерами (с навигацией)
- **🔍 Проверка текста**: Отправьте предложение с пропуском (_____), и бот найдёт паронимы в тексте
- **🏆 Таблица лидеров**: Рейтинг пользователей по количеству правильных ответов и лучшей серии
- **📊 Статистика**: Отслеживание прогресса (правильные/неправильные ответы, серии)
- **Обратная связь**: Объяснения при неправильных ответах с определениями обоих слов

## Как добавлять новые паронимы

Все данные хранятся в файле `data/paronyms.json`. Чтобы добавить новые паронимы:

1. Откройте файл `data/paronyms.json`
2. Добавьте новый объект в массив `paronyms`
3. Следуйте формату существующих записей

### Формат записи паронима:

```json
{
  "id": 4,
  "words": ["слово1", "слово2"],
  "definitions": {
    "слово1": "Определение первого слова",
    "слово2": "Определение второго слова"
  },
  "examples": {
    "слово1": "Пример предложения с первым словом",
    "слово2": "Пример предложения со вторым словом"
  },
  "test_questions": [
    {
      "sentence": "Предложение с пропуском _____ .",
      "correct": "слово1",
      "explanation": "Пояснение, почему правильный ответ — слово1"
    },
    {
      "sentence": "Другое предложение с пропуском _____ .",
      "correct": "слово2",
      "explanation": "Пояснение, почему правильный ответ — слово2"
    }
  ]
}
```

### Важные правила:

1. **id**: Уникальный номер для каждой пары паронимов (используйте следующие числа по порядку)
2. **words**: Массив из двух слов-паронимов
3. **definitions**: Объект с определениями для каждого слова
4. **examples**: Объект с примерами предложений для каждого слова
5. **test_questions**: Массив с тестовыми вопросами (может быть один или несколько)
   - **sentence**: Предложение с пропуском (используйте _____ для обозначения пропуска)
   - **correct**: Правильный ответ (должен совпадать с одним из слов в массиве words)
   - **explanation**: Пояснение, почему этот ответ правильный

### Пример добавления новой пары:

Добавьте в `data/paronyms.json` после существующих записей:

```json
{
  "id": 4,
  "words": ["памятный", "памятливый"],
  "definitions": {
    "памятный": "то, что сохраняется в памяти, достойный воспоминания",
    "памятливый": "тот, кто хорошо помнит, обладающий хорошей памятью"
  },
  "examples": {
    "памятный": "Этот день остался памятным для всех.",
    "памятливый": "Мой дедушка был очень памятливым человеком."
  },
  "test_questions": [
    {
      "sentence": "Эта встреча останется _____ в моей памяти.",
      "correct": "памятной",
      "explanation": "Памятный — то, что сохраняется в памяти."
    },
    {
      "sentence": "_____ человек никогда не забывает обещаний.",
      "correct": "Памятливый",
      "explanation": "Памятливый — тот, кто хорошо помнит."
    }
  ]
}
```

После добавления новых данных:
1. Сохраните файл `data/paronyms.json`
2. Перезапустите бота (если он был запущен)
3. Новые паронимы автоматически появятся в тренировке и словаре

## Архитектура и разделение логики

Бот спроектирован с чётким разделением логики и данных:

- **Данные**: Все паронимы хранятся в `data/paronyms.json` (исходный формат)
- **База данных**: SQLite база (`data/bot_database.db`) создаётся автоматически из JSON файла
- **Логика бота**: Обработчики в `handlers/` и клавиатуры в `keyboards/`
- **Работа с данными**: `utils/database.py` и `utils/data_manager.py` — модули для работы с базой данных

**Преимущества этого подхода:**
- Вы можете добавлять любые данные в JSON без изменения кода бота
- При запуске бота данные автоматически загружаются в SQLite базу
- База данных обеспечивает надёжное хранение статистики и таблицы лидеров
- Код бота остаётся чистым и понятным

## Технические детали

- **Библиотека**: pyTelegramBotAPI (telebot) 4.14.0 — простая и стабильная библиотека
- **Хранение данных**: JSON для паронимов (удобно редактировать вручную) + SQLite для статистики
- **Статистика**: Сохраняется в SQLite базе данных автоматически
- **Код**: Полностью на русском языке с комментариями
